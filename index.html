Current Work

My latest project is a modified fork of Claurst, a Rust terminal coding agent, focused on an experimental Python REPL-driven agent loop. The root model writes Python into a persistent REPL where Claurst tools such as Read, Bash, Glob, and Grep are exposed as callable functions. The loop continues until the model returns a final answer, while JSONL traces capture model outputs, extracted code, tool calls, helper LLM calls, and REPL state for inspection.
